# 🐦 Flappy Bird Clone (HTML, JavaScript, Phaser)

This project is a simple Flappy Bird–style game built using HTML and JavaScript with the Phaser framework, developed and tested using VS Code and Live Server. The game focuses on core gameplay mechanics, where the player controls a bird that jumps upward on input while gravity continuously pulls it downward.

The implementation includes basic physics-based movement, procedural pipe generation, and collision detection to trigger game-over states. The project is intentionally minimal and does not include score tracking, making it easy to understand and ideal for beginners exploring 2D game development with Phaser.

Key concepts demonstrated:

- Phaser game loop and scene management
- Gravity and jump mechanics
- Obstacle spawning and movement
- Collision detection using Phaser physics
- Browser-based game execution

This project serves as a foundational web game prototype and a starting point for future enhancements such as scoring, animations, or sound effects.
